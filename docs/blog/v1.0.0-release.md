SP was born from a simple yet ambitious vision: to unite the blistering runtime performance of native compiled languages like C++ with the developer happiness, expressive syntax, and modern tooling of TypeScript, Go, and Python.

With SP 1.0.0, that vision is now a reality.

---

## What is SP?

SP is a statically typed, native compiled programming language powered by an LLVM backend. It delivers:

1. **Native LLVM Machine Speed:** Zero runtime interpretation. SP compiles straight to optimized machine code with support for `-O0`, `-O1`, `-O2`, `-O3`, and `-Os`.
2. **Multi-Syntax Compatibility:** Write code using modern functional style, C++/Java OOP syntax, or concise Pythonic blocks.
3. **Built-in Package Manager (`spm`):** Full SemVer resolution, lockfile dependency tracking, and cryptographic SHA-256 tampering verification.
4. **First-Class Developer Experience:** Complete out-of-the-box LSP language server (`spls`), DAP debugger (`spd`), formatter (`spc fmt`), test runner (`spc test`), and documentation generator (`spc doc`).
5. **Memory Safety & Modern Ergonomics:** Safe navigation (`?.`), null-coalescing (`??`), pattern matching, generics, and algebraic types ensure stability without sacrificing raw execution speed.

## The Complete Toolchain

A modern language is only as good as its tooling. SP ships as a complete ecosystem:
- **`spc`**: Compiler with native code generation, formatting (`fmt`), testing (`test`), and documentation generation (`doc`).
- **`spm`**: Package manager with dependency resolution, lockfiles, and cryptographic verification (`verify`).
- **`spls`**: Language Server Protocol (LSP) daemon providing autocomplete, hover documentation, diagnostics, and code formatting in editors.
- **`spd`**: Debug Adapter Protocol (DAP) debugger with breakpoints, stepping, and inspection.
- **Official VS Code Extension:** Syntax highlighting, snippets, and LSP/DAP integration.

## Getting Started in 60 Seconds

### Install on Windows (PowerShell)
```powershell
irm https://splang.shantopaul.com/install.ps1 | iex
```

### Install on Linux & macOS (Bash)
```bash
curl -fsSL https://splang.shantopaul.com/install.sh | sh
```

### Run Your First Program
```sp
fn main() -> int {
    println("Hello, SP 1.0.0!");
    return 0;
}
```
```bash
spc run main.sp
```
