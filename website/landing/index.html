    if (n <= 1) return 1;
    return n * factorial(n - 1);

Why Developers Love SP 2.0

Architected from the ground up for developer productivity, zero-cost memory safety, and maximum execution speed.

⚡

Compile-Time Execution (comptime)

Execute pure SP functions, table generation, and compile-time assertions at build time. Zero runtime tax.

🏛️

Language Editions (2026 & 2028)

Perpetual backwards compatibility for existing packages while adopting modern syntax with automated migration (spc fix).

🌐

First-Class WebAssembly (wasm32-wasi)

Target Cloudflare Workers, edge sandboxes, and browser runtimes directly using spc build --target wasm32-wasi.

🔄

Structured async / await Coroutines

Cooperative, non-blocking asynchronous programming baked into the language with zero allocations and threadpool integration.

🛡️

Leak-Free ARC Memory Model

Deterministic Automated Reference Counting (ARC) with zero stop-the-world garbage collection pauses and zero memory leaks.

📦

Package Manager & Registry GA

Production package publishing and dependency management at registry.splang.shantopaul.com with cryptographic lockfiles.
