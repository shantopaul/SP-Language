SP Programming Language Documentation

Welcome to the official technical documentation for SP v3.0.0. SP is a modern statically-typed programming language providing bare-metal LLVM machine performance, high-throughput backend application framework (std.web), database pooling (std.db), Redis caching, WebSockets, OpenAPI 3.0 generation, and minimal static containerization.

Enterprise Milestone (SP 3.0.0 General Availability)
SP 3.0 delivers the complete enterprise cloud-native backend platform: official high-level Web Framework (std.web), sub-microsecond Radix routing, connection pooling (SQLite & PostgreSQL), in-memory zero-socket HTTP testing (std.test.http), automated OpenAPI 3.0 & Swagger UI, RFC 6455 WebSockets, Redis client & Pub/Sub, Prometheus metrics, and static musl Docker containerization (< 15MB). 474/474 automated CI test suites passing (100% pass rate).

Web Framework (std.web.app)

Instantiate the App class, attach global middlewares, define route handlers, and bind ports:

import std.io;
import std.web;

fn main() {
    let app = new App();
    app.use(new Logger());
    app.use(new Cors());
    app.use(new Recovery());

    app.get("/api/v1/health", (ptr req) => {
        let ctx = Context.create(req);
        return ctx.json("{\"status\":\"UP\",\"version\":\"3.0.0\"}");
    });

    app.listen(8080);
}

Context & Request Ergonomics (ctx)

The Context facade provides zero-copy parameter extraction and fluent response builders:

app.get("/api/v1/users/:id", (ptr req) => {
    let ctx = Context.create(req);
    let id = ctx.param("id");
    let queryLimit = ctx.query("limit");
    let authHeader = ctx.header("Authorization");
    return ctx.json("{\"id\":\"" + id + "\",\"name\":\"Alice\"}");
});

Dependency Injection (std.web.di)

Register database connection pools, services, and loggers as singletons or factories in the IoC container:

let container = new Container();
let dbPool = Database.sqlitePool("prod.db", 10);
container.bindValue("db_pool", dbPool);

let service = container.resolveValue("db_pool");

OpenAPI 3.0 & Interactive Swagger UI

Generate OpenAPI 3.0.3 contracts from source code and serve embedded Swagger UI at /docs:

# CLI command
spc doc src/main.sp --openapi -o openapi.json
spc doc src/main.sp --swagger -o docs/

// Runtime embedded viewer
app.swagger("/docs", "/openapi.json", "E-Commerce API");
app.redoc("/redoc", "/openapi.json", "E-Commerce API");

In-Memory HTTP Testing (std.test.http)

Zero network socket binding overhead. Full-stack integration tests run in under 1ms:

import std.web;
import std.test.http;

test "User Endpoint Verification" {
    let app = new App();
    app.get("/api/ping", (ptr req) => Context.create(req).json("{\"pong\":true}"));

    let client = TestClient.fromApp(app);
    let res = client.get("/api/ping");
    res.assertOk()
       .assertHeader("Content-Type", "application/json")
       .assertBodyContains("pong");

    res.destroy();
    client.destroy();
}

Database Layer & Connection Pooling (std.db)

High-concurrency thread-safe connection pooling for SQLite and PostgreSQL:

import std.db;

let pool = Database.sqlitePool("app.db", 16);
let conn = pool.acquire();
conn.execute("CREATE TABLE IF NOT EXISTS users (id INT, name TEXT);");
let rows = conn.query("SELECT * FROM users;");
pool.release(conn);

Security, JWT & Argon2id Cryptography

RFC 9106 Argon2id password hashing, JWT HS256 tokens, and constant-time attack prevention:

import std.security;
import std.crypto;

// Memory-hard password hash & verify
let hash = Password.hash("plain_password");
let isValid = Password.verify("plain_password", hash);

// JWT HS256 token minting & verification
let token = Jwt.sign("{\"sub\":\"108\",\"role\":\"admin\"}", "secret_key");
let claims = Jwt.verify(token, "secret_key");

WebSockets (RFC 6455) & Server-Sent Events

Full-duplex RFC 6455 WebSockets with WebSocketHub room broadcasting:

import std.net.ws;

let hub = new WebSocketHub();
app.get("/ws/chat", (ptr req) => {
    let conn = WebSocketConnection.upgrade(req);
    hub.register(conn);
    hub.joinRoom("general", conn);

    while (conn.isOpen()) {
        let msg = conn.receiveText();
        hub.broadcastToRoom("general", msg);
    }
    return "";
});

Redis Caching & Distributed Pub/Sub (std.redis)

Zero-allocation RESP2/3 parser, connection pooling, and cross-instance Pub/Sub messaging:

import std.redis;

let redisPool = new RedisPool("127.0.0.1", 6379, 10);
let client = redisPool.acquire();
client.setex("user:108:profile", 300, "{\"name\":\"Alice\"}");
let data = client.get("user:108:profile");
redisPool.release(client);

Background Job Queues & Cron Schedulers (std.queue)

In-process worker threadpool, exponential backoff retries, and cron scheduling:

import std.queue;

let queue = new JobQueue(4);
queue.registerHandler("email.send", (payload) => {
    println("Sending email to: " + payload);
}, 3, 1000);

queue.enqueue("email.send", "user@example.com");

Cron.schedule("*/5 * * * *", () => {
    println("5-minute cleanup running...");
});

Static Musl Compilation & Docker Scratch Container

Produce zero-dependency static binaries that run directly on bare scratch under 15MB:

FROM debian:bookworm-slim AS builder
WORKDIR /app
COPY . .
RUN spc build src/main.sp --static --release -o server

FROM scratch
WORKDIR /app
COPY --from=builder /app/server /app/server
EXPOSE 8080
ENTRYPOINT ["/app/server"]

2. Your First Program

Create a file named main.sp:

fn main() -> int {
    let message = "Hello from SP 2.0!";
    println(message);
    return 0;
}

Run it immediately:

spc run main.sp

Compile to native binary with optimizations:

spc build -O3 -o myapp main.sp
./myapp

4. Language Editions (2026 & 2028)

SP 2.0 introduces language editions, guaranteeing perpetual backwards compatibility for older codebases while unlocking modern syntax and stricter safety:

# In sp.toml
[package]
name = "my_app"
version = "2.0.0"
edition = "2028" # Or "2026" for legacy baseline

Pass the edition directly to the compiler CLI:

spc build --edition 2028 src/main.sp

5. Compile-Time Function Execution (comptime)

Execute deterministic logic, generate lookup tables, and run compile-time assertions at build time with zero runtime overhead:

comptime fn fibonacci(n: int): int {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

fn main(): int {
    // Evaluated at compile-time and folded directly into integer constant 55
    const FIB_10: int = comptime fibonacci(10);
    println("Fibonacci(10) computed at comptime: ${FIB_10}");
    return 0;
}

// Type inference
let inferredFloat = 42.5;   // Inferred as float

5. Classes & Object-Oriented Programming

SP features a clean OOP model with single inheritance, multiple interfaces, and constructors:

interface Printable {
    fn printDetails() -> void;
}

class Entity {
    public int id;
    public constructor(id: int) { this.id = id; }
}

class User extends Entity implements Printable {
    public string username;

    public constructor(id: int, username: string) : super(id) {
        this.username = username;
    }

    public override fn printDetails() {
        println("User #${this.id}: ${this.username}");
    }
}

6. SP Package Manager (SPM)

SPM handles dependencies, compilation, and registry publishing:

  • spm add <pkg>: Add dependency to sp.toml
  • spm install: Download dependencies and generate sp.lock
  • spm verify: Audit cryptographic checksums and lockfile integrity
  • spm build --release: Compile optimized binaries
  • spm publish: Publish packages to https://registry.splang.shantopaul.com
