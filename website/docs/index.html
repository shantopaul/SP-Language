SP Programming Language Documentation

Welcome to the official technical documentation for SP v2.0.0. SP is a modern statically-typed programming language providing native LLVM machine performance, compile-time function execution (comptime), language editions, first-class WebAssembly, and unified IDE tooling.

Production Release (v2.0.0 General Availability)
SP 2.0.0 delivers the full language edition system (edition = "2028"), compile-time function execution (comptime), native wasm32-wasi WebAssembly code generation, structured coroutines (async/await), and automated migration tooling (spc fix).

1. Installation

Install the SP compiler toolchain using the one-line installer for your platform:

Windows (PowerShell)

irm https://dl.splang.shantopaul.com/install.ps1 | iex

Linux & macOS (Bash)

curl -fsSL https://dl.splang.shantopaul.com/install.sh | sh

Confirm the installation succeeded:

spc --version
spm --version

2. Your First Program

Create a file named main.sp:

fn main() -> int {
    let message = "Hello from SP 2.0!";
    println(message);
    return 0;
}

Run it immediately:

spc run main.sp

Compile to native binary with optimizations:

spc build -O3 -o myapp main.sp
./myapp

3. Project Management with SPM

Initialize a new application:

spm init my_service
cd my_service
spm run

Verify package integrity and detect any lockfile tampering:

spm verify

4. Language Editions (2026 & 2028)

SP 2.0 introduces language editions, guaranteeing perpetual backwards compatibility for older codebases while unlocking modern syntax and stricter safety:

# In sp.toml
[package]
name = "my_app"
version = "2.0.0"
edition = "2028" # Or "2026" for legacy baseline

Pass the edition directly to the compiler CLI:

spc build --edition 2028 src/main.sp

5. Compile-Time Function Execution (comptime)

Execute deterministic logic, generate lookup tables, and run compile-time assertions at build time with zero runtime overhead:

comptime fn fibonacci(n: int): int {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

fn main(): int {
    // Evaluated at compile-time and folded directly into integer constant 55
    const FIB_10: int = comptime fibonacci(10);
    println("Fibonacci(10) computed at comptime: ${FIB_10}");
    return 0;
}

6. First-Class WebAssembly (wasm32-wasi)

Compile high-performance SP binaries directly to WebAssembly System Interface (WASI) for serverless edge workers and browser runtimes:

spc build --target wasm32-wasi -o service.wasm src/main.sp
wasmtime service.wasm

7. Structured async / await Coroutines

Native asynchronous functions and tasks with seamless threadpool event-loop integration:

async fn fetchRemoteData(url: string): string {
    let client = new HttpClient();
    let resp = await client.get(url);
    return resp.body;
}

8. Automated Migration Tool (spc fix)

Automatically inspect and upgrade legacy codebases to Edition 2028:

spc fix --edition 2028 --dry-run src/
spc fix --edition 2028 src/

9. Variables & Data Types

SP supports explicit type annotations as well as automatic type inference:

let name: string = "Alice"; // Immutable
var score: int = 100;       // Mutable
const MAX_USERS: int = 500;  // Constant

// Type inference
let inferredFloat = 42.5;   // Inferred as float
let inferredBool = true;    // Inferred as bool

5. Classes & Object-Oriented Programming

SP features a clean OOP model with single inheritance, multiple interfaces, and constructors:

interface Printable {
    fn printDetails() -> void;
}

class Entity {
    public int id;
    public constructor(id: int) { this.id = id; }
}

class User extends Entity implements Printable {
    public string username;

    public constructor(id: int, username: string) : super(id) {
        this.username = username;
    }

    public override fn printDetails() {
        println("User #${this.id}: ${this.username}");
    }
}

6. SP Package Manager (SPM)

SPM handles dependencies, compilation, and registry publishing:

  • spm add <pkg>: Add dependency to sp.toml
  • spm install: Download dependencies and generate sp.lock
  • spm verify: Audit cryptographic checksums and lockfile integrity
  • spm build --release: Compile optimized binaries
  • spm publish: Publish packages to https://registry.splang.shantopaul.com

7. VS Code Extension & Language Server (spls)

SP provides an official Visual Studio Code extension with full syntax highlighting, TextMate grammar, snippets, and LSP autocomplete:

Install in one command (PowerShell):

irm https://dl.splang.shantopaul.com/sp-vscode.vsix -OutFile "$env:TEMP\sp-vscode.vsix"; code --install-extension "$env:TEMP\sp-vscode.vsix"

Or download the package directly: sp-vscode.vsix (11.8 KB) and select Install from VSIX... in VS Code.

8. Debug Adapter Protocol (spd)

SP includes spd for interactive source-level debugging with step-in, step-over, breakpoints, and live variable inspection in VS Code.
